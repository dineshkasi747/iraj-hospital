# IRAJ Hospitals & Research Centre

A modern, responsive Next.js web application for **IRAJ Multi-Speciality Hospitals** located in Gajuwaka, Visakhapatnam.

## Features
- **Modern Next.js Architecture**: Server & client components with dynamic routing and optimized performance.
- **Patient Authentication & Security Gate**: Supabase-powered authentication for patient profiles, medical appointments, and locked doctor directory access.
- **Doctor Directory & Clinical Profiles**: Comprehensive doctor profiles with qualifications, specialities, awards, and consultation booking.
- **Mobile-First Bottom Dock & Peacock Fan Radial Menu**: App-like mobile navigation featuring an interactive Peacock radial arc menu.
- **Appointment Management**: Online patient appointment booking with instant WhatsApp token routing and Supabase integration.
- **Clinical Services & Departments**: Dedicated pages for General Medicine, Surgery, Orthopedics, Cardiology, Pediatrics, Gynaecology, ICU/AMCU, and Diagnostics.
- **Emergency & OPD Information**: Real-time ticker and 24/7 hotline helpline connectivity.

## Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Bootstrap 5 & Vanilla CSS
- **Backend & Auth**: Supabase (Live Auth & PostgreSQL)
- **Icons**: FontAwesome 6 Pro & Free
- **Animations**: Wow.js & Animate.css

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
